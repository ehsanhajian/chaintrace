ChainTrace

ChainTrace answers one question: what is a blockchain node doing internally?

It reads the process, the files that process has open, and the connections it holds. A short read-only eBPF probe is there when you ask for one. A finding is printed when that behavior does not belong on a node.

ValidatorPulse raises an alert. ChainDiff decides whether an upgrade is safe. chainlog-ai explains a failure from the logs. ChainTrace is the view of the process itself.

Install

pip install chaintrace

Python 3.11 or newer. The package is on PyPI. Commands, client profiles, and the saved examples are in the README.
